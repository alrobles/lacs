# Get a document term matrix from abstracts

Get a document term matrix from abstracts

## Usage

``` r
get_dtm(abstracts, vocabulary, tf_idf = TRUE)
```

## Arguments

- abstracts:

  Could be an object of class abstracts (created via `get_abstracts`
  function) or a `character`vector with abstracts

- vocabulary:

  A vocabulary created with the `get_vocabulary` function, from an
  `abstracts` object

- tf_idf:

  logical. If it is true returns dtm weighted with tf idf. Otherwise
  return binary dtm matrix

## Value

Returns a document term matrix. Each row is a document, each term is a
matrix from vocabulary

## Examples

abstracts <- get_abstracts(lacsSample)
vocabulary <- get_vocabulary(abstracts, term_count = 10)
get_dtm(abstracts, vocabulary, tf_idf = FALSE)
