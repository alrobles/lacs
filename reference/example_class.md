# Vector with 100 examples of class of abstracts from papers. Is used as an example to build an abstracts class. Could be positive (belonging to the corpus of mammal - parasite papers) or unknown.

Vector with 100 examples of class of abstracts from papers. Is used as
an example to build an abstracts class. Could be positive (belonging to
the corpus of mammal - parasite papers) or unknown.

## Usage

``` r
data(example_class)
```

## Format

An object of class `"character"` with 100 classes of abstracts.

## Examples

``` r
data(example_class)
```
