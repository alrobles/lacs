# Get the independent variable for an abstracts object

Get the independent variable for an abstracts object

## Usage

``` r
get_y(abstracts)
```

## Arguments

- abstracts:

  An object of class abstracts is a data frame with a class column.
  Shoiuld have possitive and unknown classes

## Value

A vector of binary output
